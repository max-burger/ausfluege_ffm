# Ausflüge ab Rödelheim

Private Familienkarte mit Ausflugszielen rund um Frankfurt (Natur, Burgen, Parks, kleine Altstädte),
erreichbar mit Bus und Bahn. Zugang nur mit Anmeldung.

- Karte: [MapLibre](https://maplibre.org), Kartendaten © OpenStreetMap-Mitwirkende, OpenMapTiles, OpenFreeMap
- Fotos der Orte: Wikimedia Commons, Urheber und Lizenz stehen jeweils am Bild
- Fahrplandaten: DELFI über Transitous
- Daten und Anmeldung: Supabase
